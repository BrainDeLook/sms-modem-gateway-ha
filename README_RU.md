# SMS Modem Gateway для Home Assistant

Надёжный аддон для приёма и отправки SMS через USB GSM-модем. Аддон использует
`python-gammu` только как драйвер модема, а сборку multipart-UDH, хранение,
очистку SIM и REST-очередь реализует собственным кодом.

## Установка

Добавь репозиторий в **Настройки → Дополнения → Магазин дополнений → ⋮ →
Репозитории**:

```text
https://github.com/BrainDeLook/sms-modem-gateway-ha
```

Установи **SMS Modem Gateway**, выбери serial-устройство модема, задай логин и
пароль и запусти аддон. Не запускай другой SMS-шлюз на том же порту модема.

После этого установи [SMS Gammu Viewer](https://github.com/BrainDeLook/sms-gammu-viewer-ha)
через HACS и укажи в интеграции REST API аддона на порту `5000`.

## Надёжность

1. Аддон читает физические записи модема без `gammu.LinkSMS`.
2. Разбирает стандартные 8-битные и 16-битные concat-UDH.
3. Ждёт полный непротиворечивый набор частей.
4. Сохраняет логическое SMS и журнал очистки в SQLite.
5. Удаляет только записи модема с совпадающим отпечатком.
6. Передаёт готовые сообщения через долговечную REST-очередь с подтверждением по ID.

MQTT в аддон намеренно не включён. Голосовые звонки выполняются самой
интеграцией через отдельный serial-порт модема.

См. [описание REST API](sms-modem-gateway/LEAN_API.md).
